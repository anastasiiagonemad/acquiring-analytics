# Эквайринг-Аналитика (Сверка эквайринга)

Клиентское SPA на Vue 3 для сверки банковского эквайринга по оборотно-сальдовой ведомости (ОСВ) счёта **57.03** из 1С.

Мама загружает Excel-файл ОСВ — приложение показывает расхождения по договорам/салонам: излишки (непробитые чеки) и задержки банка. **Все расчёты выполняются только в браузере**, данные никуда не отправляются.

## Стек

- Vue 3 + Vite + TypeScript (Composition API, `<script setup>`)
- Чистый scoped CSS (без Tailwind и тяжёлых UI-китов)
- SheetJS (`xlsx`) для чтения Excel
- Vitest — юнит-тесты парсера и логики

## Быстрый старт

```bash
npm install
npm run dev      # локальная разработка
npm test         # юнит-тесты
npm run build    # сборка в dist/
```

## GitHub Pages

В репозитории есть workflow `.github/workflows/deploy-pages.yml`:

1. Запушьте проект в GitHub (ветка `main` или `master`).
2. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
3. После пуша Actions соберёт `dist/` и опубликует сайт.
4. В `vite.config.ts` задано `base: './'` — относительные пути для Pages.

## Конфиденциальность

Файл ОСВ обрабатывается **только на устройстве пользователя**. Серверного бэкенда нет, финансовые данные не загружаются в облако.

## AI-помощник

В дашборде есть чат с двумя режимами:

### Локальный помощник (по умолчанию)

Работает **сразу, без ключей и сети**. Отвечает по уже разобранному файлу ОСВ: где излишки (OVERPAYMENT), какие даты смотреть, что делать с недостачей (UNDERPAYMENT) — сверка слип-чеков vs запрос в банк. Данные не покидают браузер.

### Gemini (бесплатно, опционально)

1. Получите бесплатный API-ключ: [Google AI Studio](https://aistudio.google.com/apikey).
2. В чате откройте **Настройки**, вставьте ключ и нажмите «Сохранить» (хранится в `localStorage` под ключом `acquiring-analytics-gemini-key`).
3. Переключите режим на **Gemini**.

В облако уходит только **компактная текстовая сводка** аномалий (названия салонов, даты, статусы, суммы) — не исходный Excel. В интерфейсе есть явное предупреждение об этом.
